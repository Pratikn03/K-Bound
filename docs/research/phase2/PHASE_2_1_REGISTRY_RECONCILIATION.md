# Phase 2.1 — Registry / Report Reconciliation

**Status:** REPAIR. Resolves the contradiction between the locked Phase-2 registry and the post-pilot report's description of Family-A cells.

## 1. Drift identified

The original locked registry [PHASE_2_EXPERIMENT_REGISTRY.csv](./PHASE_2_EXPERIMENT_REGISTRY.csv) defines A-POWERED-2..5 as:

| Cell | Benchmark | Protocol |
|---|---|---|
| A-POWERED-2 | MVTec 3D-AD | PatchCore held-out category |
| A-POWERED-3 | MVTec LOCO-AD | PatchCore supervised-paired |
| A-POWERED-4 | VisA | RGB+edge supervised-paired |
| A-POWERED-5 | UNSW-NB15 | flow/conn/context |

The v1 Family-A report [FAMILY_A_POWERED_AUDITED_REPRODUCTION_REPORT.md](./FAMILY_A_POWERED_AUDITED_REPRODUCTION_REPORT.md) §4 instead listed A-POWERED-2..5 as Real3D / EfficientAD expansions of MVTec 3D-AD:

| Cell (v1 report — INCORRECT) | Benchmark | Protocol |
|---|---|---|
| A-POWERED-2 | MVTec 3D-AD | PatchCore one-class |
| A-POWERED-3 | MVTec 3D-AD | EfficientAD supervised-paired |
| A-POWERED-4 | MVTec 3D-AD | EfficientAD one-class |
| A-POWERED-5 | Real3D | PatchCore supervised-paired |

This is contract drift. The post-pilot report silently substituted different cells for the registry's locked cells.

## 2. Resolution rule

**The registry wins.** The locked Family-A cell identities are those in §1 first table. The v2 Family-A report ([FAMILY_A_POWERED_AUDITED_REPRODUCTION_REPORT_v2.md](./FAMILY_A_POWERED_AUDITED_REPRODUCTION_REPORT_v2.md)) restores them.

## 3. Where EfficientAD / Real3D expansions go

EfficientAD and Real3D expansions are useful and may be added — but they cannot be placed inside Family A. They go into Family C as separately numbered exploratory cells:

- `C-EXP-EFFICIENTAD-1` — MVTec 3D-AD, EfficientAD supervised-paired.
- `C-EXP-EFFICIENTAD-2` — MVTec 3D-AD, EfficientAD one-class.
- `C-EXP-REAL3D-1` — Real3D, PatchCore supervised-paired.
- `C-EXP-REAL3D-2` — Real3D, PatchCore one-class.

Family C carries no Holm correction; its outputs are descriptive. Adding these cells to Family C does **not** alter the Family-A K = 5 multiplicity-family.
