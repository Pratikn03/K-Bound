Test-time adaptation can help without target labels, but updates can harm. We ask when label-free
evidence supports a directionally correct action: ADAPT for a helpful fixed candidate, FREEZE for a
harmful one, or explicit ABSTAIN. We report false-action denominators and utility preservation before
regret consequences. For binary $0/1$ loss, K-Bound uses
$\operatorname{sign}(\Delta)=\operatorname{sign}(M+\gamma)$ and a declared bound $\beta$ on the hidden
residual $\gamma$. The compatible-benefit set supports a strict direction exactly when
$|M|>\beta$. An evidence-fibre theorem further shows that additional functions of the same
label-free evidence cannot certify a smaller residual range.
Knowability-Guided Adaptation (\KGA) is an empirical companion, not an implementation of this
frontier. Using labeled development and residual-calibration cells, it fits and calibrates a
predictor of measured evaluation-cell benefit $\Delta^{\mathrm{cell}}$; the scored cell contributes
label-free evidence only. On the opened, dependent,
constructed six-family CIFAR-10-C diagnostic, Tent has 2/1,091 false ADAPT (2/2,160 overall) and
1/337 false FREEZE; EATA has 0/1,207 false ADAPT and 0/105 false FREEZE; SAR exposes 1,414 ADAPT
decisions and no FREEZE exposure. As secondary consequences, Tent and EATA have lower point regret
than both fixed policies, whereas SAR favors always-adapt. On CCT-20, \KGA makes
\CCTAdaptCount{}/\CCTFreezeCount{}/\CCTAbstainCount{} ADAPT/FREEZE/ABSTAIN decisions. All
\CCTCellCount{} served predictions use the frozen model, but the sole helpful cell receives FREEZE,
yielding \CCTFalseFreezeCountWord{} false FREEZE among \CCTFalseFreezeConditionalDenominator{} FREEZE
actions (\CCTFalseFreezeCount{}/\CCTFalseFreezeOverallDenominator{} overall). CCT-20 therefore
supports only the locked utility-preservation endpoint, not selective routing. These protocol-scoped
results do not establish interval coverage or population-risk protection on unseen natural shifts.
