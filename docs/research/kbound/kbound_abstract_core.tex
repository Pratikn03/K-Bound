Test-time adaptation can help without target labels, but updates can harm. We ask when label-free
evidence supports a directionally correct action: ADAPT for a helpful fixed candidate, FREEZE for a
harmful one, or explicit ABSTAIN. We report false-action denominators and utility preservation before
regret consequences. For
binary $0/1$ loss, K-Bound uses
$\operatorname{sign}(\Delta)=\operatorname{sign}(M+\gamma)$ and a declared bound $\beta$ on hidden
residual $\gamma$. The resulting compatible-benefit set supports a strict direction exactly when
$|M|>\beta$; an evidence-fibre theorem shows why the same observations cannot reduce this range.
Knowability-Guided Adaptation (\KGA) is an empirical companion, not an implementation of the
frontier. Using labeled development and residual-calibration cells, it fits and calibrates a
predictor of observed evaluation-cell benefit $\Delta^{\mathrm{cell}}$. The scored cell contributes
label-free evidence only; $\widehat\Delta\pm\varepsilon$ selects ADAPT, FREEZE, or ABSTAIN. On the opened,
dependent, constructed six-family CIFAR-10-C diagnostic, Tent has 2/1,091 false ADAPT (2/2,160
overall) and 1/337 false
FREEZE; EATA has 0/1,207 false ADAPT and 0/105 false FREEZE; SAR exposes 1,414 ADAPT decisions and no
FREEZE exposure. As secondary consequences, Tent and EATA have lower point regret than both fixed
policies, whereas SAR favors always-adapt. On CCT-20, KGA made
\CCTAdaptCount{}/\CCTFreezeCount{}/\CCTAbstainCount{} ADAPT/FREEZE/ABSTAIN decisions. All
\CCTCellCount{} served predictions used the frozen model, but the sole helpful cell received FREEZE,
yielding \CCTFalseFreezeCountWord{} false FREEZE among \CCTFalseFreezeConditionalDenominator{} FREEZE
actions (\CCTFalseFreezeCount{}/\CCTFalseFreezeOverallDenominator{} overall). The study therefore
passes only the locked safe-utility check and does not demonstrate selective routing or strong
success. These retrospective,
protocol-scoped results do not establish interval coverage or population-risk protection on unseen
natural shifts.
