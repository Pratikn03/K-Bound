# Retired PDF aliases

These exact local PDF bytes were preserved with user approval before removal
from the active publication path set. They are historical review artifacts,
not current release deliverables. No pages were edited and no numerical result
was changed. MANIFEST.json records their independently measured pre-move sizes
and SHA-256 hashes. Move the files back only as an explicit recovery operation;
doing so would reintroduce the publication-identity conflict.
