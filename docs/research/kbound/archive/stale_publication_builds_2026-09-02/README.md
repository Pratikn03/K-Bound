# Historical publication-build recovery

These ten pinned historical PDF/DOCX blobs are **not release deliverables**.
They were recovered on 2026-09-20 from local Git commit
`660d893caede49c3b7daa8c18e43bb6cbbce5480`, after the expected archive was
found missing. The date in this directory name identifies the historical
archive contract; it is not the recovery date.

`MANIFEST.json` records exact Git-derived bytes and SHA-256 identities.
Its `canonical_outputs` and `replacement_outputs` fields preserve the old
three-artifact contract for historical audit compatibility. They do not select
or authenticate the current publication package, whose source, runtime and
artifact contract remain governed by the living execution plan.

Recovery did not rebuild any document, move a current PDF/DOCX, remove a
divergent original, alter numerical evidence, or certify a publication release.
The complete originals are retained here under `tree/` with their pinned paths.
