\chapter{Complete Result Tables}\label{app:tables}

This appendix contains the full numerical tables for all primary experiments reported in
Chapter~\ref{ch:exp1} (anomaly-routing benchmark) and Chapter~\ref{ch:exp2} (TTA and
CIFAR-10 experiments).  Each table identifies its source JSON file and field path.
Numbers are reproduced verbatim from the JSON files without rounding beyond what floating-point
display requires.  All tables are self-contained: column headings, units, and source fields
are given in each caption.
