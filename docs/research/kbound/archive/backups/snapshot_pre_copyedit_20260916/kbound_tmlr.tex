%% kbound_tmlr.tex -- anonymous TMLR submission driver.
%%
%% This driver uses the same corrected abstract, ten-section scientific body,
%% generated numbers, theorem sources, supplement, and bibliography as the compact paper.
%% The source-hashed canonical panel remains the numerical authority for both
%% layouts. Build this companion with BUILD_LONG_TMLR=1.
%%
%% WHY THIS FILE EXISTS
%%   The IEEEtran two-column build (kbound_short.tex) ran to 23 pages with 26
%%   tables, which is a desk-reject risk at a conference and, more importantly,
%%   is too dense for a reviewer to hold in mind. TMLR is single-column with no
%%   hard page limit and judges claim-evidence support rather than novelty
%%   magnitude, which is the right bar for this work. Reformatting single-column
%%   dissolves the length problem WITHOUT cutting any result table.
%%
%% ANONYMITY
%%   The official style is loaded without accepted/preprint options, so the PDF
%%   is double-blind.  \anontrue also suppresses author-identifying repository
%%   material in the shared body.  A camera-ready or preprint must be built from
%%   a separate, explicitly versioned driver rather than changing this one.
%%
%% SHARED SOURCE
%%   kbound_abstract.tex          shared abstract
%%   kbound_submission_body.tex  shared scientific main body
%%   kbound_submission_supplement.tex  supplementary material after references
%%   paper/references_kbound_expanded.tex
