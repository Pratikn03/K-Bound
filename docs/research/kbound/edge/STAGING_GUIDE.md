## Smart order — test the gate cheaply FIRST

The whole study dies if the source model can't tell the 4 states apart. So:

1. **Record S01 + S02 only** (160 clips) → train f0 → check **S02 val balanced-acc ≥ 0.80**.
   - **If it fails, STOP.** Improve the photos (clearer states, steadier framing, better light)
   and re-shoot the source. Cheaper to find out now than after the remaining 448 clips.
2. **Only if the gate passes:** record S03–S06 (calibration) → **seal** → S07–S10 (held-out + replication).

## Materials

- **10 cardboard boxes**, labeled P01–P10. Vary them (sizes / shades of brown) so the model
  learns the *label state*, not one specific box.
- **A stack of identical white labels** — real shipping labels, or white paper rectangles /
  sticky notes. You'll stick, peel, and tear them many times.
- **2 phones** — phone A (primary, S01–S08), phone B (replication, S09–S10).
- **A phone stand / tripod.** The capture tool has **no viewfinder**, so fixed framing matters.
- **A movable desk lamp + a spare backdrop/cloth** — for the lighting / shadow / glare /
  background shifts.

## Setup

- Phone on the stand, aimed at a fixed spot. Box fills most of the frame, label clearly visible.
- For **S01 / S02** (shift = `stable`): clean, even, bright light. These teach the 4 states cleanly.

---

## The 4 label states (the prompt's **Class**)

| Class | Stage it by |
|---|---|
| `ok` | Clean white label, flat, straight, correct spot |
| `missing_label` | **No label** — bare cardboard (peel it off / leave empty) |
| `misaligned_label` | Label present but **crooked** — rotate ~45–90° or hang it over an edge |
| `damaged_label` | Label present but **ruined** — torn corner, peeling, crumpled, or smeared |

## The shifts (the prompt's **Shift** — only S03–S10; S01/S02 are `stable`)

| Shift | Produce it by |
|---|---|
| `mild_light` | Dim the room / lower the lamp (noticeably darker than S01/S02) |
| `side_shadow` | Put the lamp to one side, or partly block it, so a shadow falls across the box |
| `new_background` | Different surface/cloth under or behind the box |
| `glare` | Aim the lamp so it reflects/glares off the label |
| `motion_blur` | Gently move the box (or nudge the phone) during the ~1.3 s recording |
| `viewpoint_45` | Tilt the phone (or box) to ~45°, not straight-on |
| `distance_scale` | Move the box clearly closer or farther than the source distance |

## The workflow (you follow the prompt)

You don't plan the order — the tool does. For each clip it prints, e.g.:

```
[37/128] NEXT CAPTURE:
  Object:    P03
  Class:     damaged_label
  Shift:     glare
  Place target and press ENTER to record (or Q to quit):
```

You: grab box **P03**, tear/peel its label (`damaged_label`), aim the lamp for **glare**,
press **ENTER**. It records and saves. Repeat. Press **Q** to pause; it resumes where you left off.
