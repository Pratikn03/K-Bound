## 1. Score Archive — Precomputed Detector Scores (TORCH-FREE)

**Path**: `experiments/elara_u/score_archive/`
**Total files**: 123 `.npz` files
**Schema** (uniform across all 123):
```
Sval   : (N_val, 6)  float64  — validation set anomaly scores (6 detectors)
yval   : (N_val,)    int64    — validation labels (0=normal, 1=anomaly)
Stest  : (N_test, 6) float64  — test set anomaly scores
ytest  : (N_test,)   int64    — test labels
det_names: (6,)      str      — ['ECOD','COPOD','IForest','LOF','KNN','OCSVM']
val_auc:   (6,)      float64  — per-detector validation AUC
domain:    scalar    str      — dataset domain label
```

### 1a. ADBench Tabular (42 tasks)
- **Files**: `adb_1_ALOI.npz` … `adb_47_yeast.npz` (42 of 47, some excluded for tiny N)
- **N_test**: 20–2,000 per task (total 50,256)
- **Domain tag**: `'adbench'`
- **Source**: Standard ADBench benchmark (Han et al. 2022), 47 tabular anomaly datasets
- **KGA usability**: FULLY USABLE. f0 = best-val-AUC detector, f_a = mean ensemble.

### 1b. Special Domain Score Archives (20 tasks)
| File | Domain | N_test |
|------|--------|--------|
| creditcard.npz | fraud | 2,000 |
| online_shoppers.npz | tabular | 2,000 |
| nlp_20news_0..5.npz | text | 773–2,000 |
| nlp_agnews_0..3.npz | text | 2,000 |
| nlp_amazon.npz | text | 2,000 |
| nlp_imdb.npz | text | 2,000 |
| nlp_yelp.npz | text | 2,000 |
| unsw_dos/exploits/full/fuzzers/reconnaissance.npz | cyber | 2,000 |

- **KGA usability**: FULLY USABLE (same schema as 1a).

### 1c. Image OOD Score Archives (61 tasks) — SKIPPED FOR CPU KGA
- **Files**: `cv_CIFAR10_0..9.npz`, `cv_FashionMNIST_0..9.npz`, `cv_MNIST-C_*.npz`,
  `cv_MVTec-AD_*.npz`, `cv_SVHN_0..9.npz` — 61 files total
- **N_test**: 26–2,000 (many <50 samples for rare class splits)
- **Domain tag**: `'image_ood'`
- **Skipped because**: (a) Not the covariate-shift TTA scenario (these are class-vs-rest OOD
  splits for anomaly detection, not shifting test distributions); (b) Many splits have
  N<30 test samples making skewness/kurtosis Z-features unreliable; (c) the f0/f_a
  distinction collapses because all 6 detectors see the same deep features.
