## Bugs fixed 2026-07-01 (were breaking “one command = paper story”)

1. **`kbtrain.sh cifar10c`** wrote to `cifar10c_stress/` **without `--quick`** → different grid than Protocol A / `LOCKED_ANALYSIS`. **Fixed:** `--quick` + `stress_grid_multiseed_v1/seed$S`.
2. **`collate_final.py`** labeled stress-grid files as dataset `seed0` not `cifar10c` → `build_results_source` could not find CIFAR row. **Fixed:** `stress_grid_multiseed` → `cifar10c`.
3. **`_locked_analysis_script.py`** had stale cloud path. **Fixed:** `os.path.dirname(__file__)`.
4. **Showcase** omitted locked analysis + head-to-head + mixed-stream. **Fixed:** stages H–J.

4. **Prepare RxRx1 data** at `~/kbound_rxrx1_data/rxrx1_v1.0` before full panel.
5. **Do not expect** multicandidate routing to change headline natural-shift numbers (by design).
