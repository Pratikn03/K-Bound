## 3. The question and comparison contract

**Primary research question:** Does a calibrated interval add transferable decision value beyond a development-selected fixed margin applied to the *same fitted benefit predictions*?

Required controllers are Always Freeze, Always Adapt, point-benefit gating, a development-selected fixed-margin gate, and KGA. Include an authenticated native AETTA estimator with an explicitly specified controller if task/architecture compatibility can be demonstrated; otherwise report unavailability and the reason, without claiming that comparison is complete. POEM is an adapter, not an interchangeable gate. A different candidate trajectory belongs in a separate end-to-end comparison.

The main KGA-versus-margin comparison uses the same checkpoint, candidate, features, fitted predictor, labeled development budget, score IDs, weights, and paired oracle. Preserve both ADAPT/FREEZE/ABSTAIN semantics and the fact that FREEZE and ABSTAIN serve the frozen model. AETTA's different information budget must be visible; equal outcome panels do not imply equal supervision budgets.

Bind candidate initialization, reset, optimizer and normalization state across controllers. The initial study measures routing over fixed, gate-independent candidate proposals. If accepting or rejecting an update changes later candidates, shared saved proposals no longer identify the closed-loop policy's benefit; that requires a separately specified trajectory experiment and cannot be inferred from this panel.

**Algebraic equivalence gate:** If KGA uses one symmetric radius `epsilon` and threshold zero, its rules are exactly the fixed-margin rules `h(Z) > epsilon` for ADAPT and `h(Z) < -epsilon` for FREEZE. Equal scalar margins give identical policies; matching ADAPT exposure with the same ranking may remove any behavioral distinction. First audit whether the actual radius is global, group-specific, or input-dependent and test this identity, including ties. For a global radius, the legitimate question is how a calibrated threshold-selection procedure compares with a development-only heuristic under transfer, not whether the interval is a more expressive per-cell policy. Identical policies are an informative equivalence result, not a failed experiment to tune away. For varying radii, lock their grouping/scaling and give comparators the declared equivalent information and model-selection budget. Do not add heteroscedastic complexity solely to force a difference or a favorable result.

**Source audit result (2026-09-19):** the maintained common-panel API has one scalar radius per fitted gate; crossfit has one per score fold. Six data-free tests verify exact symmetric-margin equivalence, including ties/infinite radius. At zero prediction and zero radius, point gating FREEZEs while KGA ABSTAINS, but both serve frozen. The existing historical fixed-margin comparator instead pools medians of other tasks' stored radii; its last-step task exclusion is not proof of upstream outcome isolation. The new study must compare locked threshold-selection procedures at matched information budgets; no distinct algorithmic behavior is possible when both scalar thresholds are identical. Stateful gateway and multi-candidate variants are outside that identity's full-system scope.

Before confirmation, select and lock one primary operating criterion: a development-chosen error cost or a development-matched ADAPT-exposure rule. Do not use scored outcomes or target action counts to tune the margin to match KGA. Target exposure can differ after transfer; report that difference instead of rematching it retrospectively. Secondary exposure curves use a predeclared finite grid and multiplicity/interpretation rules.

The protocol lock must specify one primary endpoint, effect direction, minimum relevant effect, statistical unit, weighting, uncertainty method, comparison family, and decision rule. Choose these using the scientific question plus development-only precision calculations, not a favorable target result. The lock is rejected if any field is unresolved.

Required reporting: paired policy accuracy and candidate-specific oracle regret; ADAPT exposure; FREEZE and ABSTAIN counts; strictly harmful ADAPT and zero-benefit ties separately; unconditional false-ADAPT rate; conditional false-ADAPT rate with its denominator; positive benefit captured; group-level results; and source/stream seed identities.
```python
import math

def select_margin(predictions, outcomes, margins, harmful_cost):
    if not predictions or len(predictions) != len(outcomes) or not margins:
        raise ValueError("nonempty aligned tuning data and margin grid required")
    if not math.isfinite(harmful_cost) or harmful_cost <= 0:
        raise ValueError("harmful_cost must be positive and finite")
    if any(not math.isfinite(x) for x in predictions + outcomes + margins):
        raise ValueError("finite tuning values required")
    if any(abs(b) > 1 for b in outcomes) or any(m < 0 for m in margins):
        raise ValueError("benefit or margin outside permitted range")
    def objective(margin):
        return sum(harmful_cost * max(-b, 0.0) if p > margin else max(b, 0.0)
                   for p, b in zip(predictions, outcomes)) / len(predictions)
    return min(set(margins), key=lambda margin: (objective(margin), -margin))
```
