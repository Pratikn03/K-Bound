## Audit-assisted design

The finite frame, predictions, class universe, score values/bin map and audit size are fixed before randomized draws. The sampler reads no labels, records a content-bound draw inventory, and samples with replacement using the operating-system random source. The statistical result is conditional on faithful labels, a fixed frame and independent uniform draws; a software hash cannot establish these facts about an external deployment.

For binary disagreement audits, the full-frame score average is known. An outward binomial interval for adapted correctness yields a confidence interval for the residual and an upper bound on its absolute value. The same interval yields a direct finite-frame paired-benefit interval. With no disagreements the paired benefit is exactly zero.

For general class labels, helpful and harmful paired outcomes are bounded separately with a union budget. Conditional harm among accepted updates is not inferred from this mean-benefit certificate.

For transport, simultaneous intervals for source and target class-conditional bins give per-class total-variation upper bounds. Target-prior intervals and an exact simplex optimization give a weighted transport-budget upper bound. Empty classes remain unconstrained. The budget is random, so its failure probability must be added to any subsequent certificate's error budget; independence is not required for that union bound. Exact numerical enclosure does not prove the sampling law.
