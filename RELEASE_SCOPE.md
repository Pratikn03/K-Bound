# Release Scope

This repository is a clean K-Bound/KGA research release with a new Git history.
It intentionally excludes the former monorepo, raw datasets, checkpoints,
historical ELARA material, stale long-manuscript claims, and unreviewed camera
media.

The authoritative manuscript is
`docs/research/kbound/kbound_short.tex`. The included PDF and Word files are
generated from that source. Compact result records are included only when they
are referenced by the canonical result manifest.

The historical 59-page `kbound.tex` is excluded because it predates the current
claim corrections. Its defensible material has already been folded into the
short paper or identified in `KBOUND_MANUSCRIPT_STRATEGY.md` for future
supplement work.
