# Archived Office-Home exploratory analysis

These scripts are retained only to reproduce and audit the historical exploratory
Office-Home analysis. They are not part of the active or promotable K-Bound
pipeline.

The archived route-B analysis predates the binary-task guard, strict exact-rank
feasibility checks, and current publication ledger. Office-Home has 65 classes,
so its agreement-based multicandidate route is invalid under the present theory.
Use `experiments/kbound/officehome/run_officehome_kbound.py` for new runs; it
records Route B as unsupported and preserves only valid raw/single-candidate
evidence.
